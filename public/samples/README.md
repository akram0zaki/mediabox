# Sample media

- `solvay.jpg` — the 1927 Solvay Conference group photograph (29 faces, 1920×1389). Public domain, from Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Solvay_conference_1927.jpg
- `solvay.mp4` — a 6-second 1280×720 H.264/AAC clip generated from the photo with a slow zoom and pan (ffmpeg `zoompan`), with a 440 Hz tone as audio. Useful for checking face tracking on moving faces.
